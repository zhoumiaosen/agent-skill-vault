Plain Agent Skills Markdown, engine-neutral concepts; examples target Godot 4.7 and Unity 6.3 LTS. Two-file complete package; no bundled executable or runtime dependency. Named UI/input/genre skills and love2d-core reference are optional cross-skill integration references, not included. Screen-stack sketches require project-provided grab_focus_default and defensive stack handling; safe-area coordinates must be adapted to actual viewport scale.

Review all commands before use; preserve project data. Publishing these files does not install or run them. Examples need adaptation to your engine version and project. Static inspection only; no runtime validation.

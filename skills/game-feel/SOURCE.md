Plain Agent Skills Markdown, engine-neutral concepts; examples target Godot 4.7 and Unity 6.3 LTS. Two-file complete package; no bundled executable or runtime dependency. Named engine/audio/camera skills are optional integration references, not included. Code examples are illustrative and not runtime-tested; hit-stop samples restore scale to 1 and need overlap/pause handling; Unity reference computes an unused 'back' value.

Review all commands before use; preserve project data. Publishing these files does not install or run them. Examples need adaptation to your engine version and project. Static inspection only; no runtime validation.
